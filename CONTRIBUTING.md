# Contributing to ChargeSheet AI Assistant

Thank you for your interest in contributing!

## Development Workflow

1. Start from the latest main branch.
2. Create a separate feature branch for each task.
3. Follow the existing project structure and coding conventions.
4. Test your changes locally.
5. Use clear and descriptive commit messages.
6. Open a pull request targeting main.
7. Review changes and resolve feedback before merging.

## Commit Message Convention

- feat: New functionality
- fix: Bug fixes
- docs: Documentation updates
- test: Test-related changes
- security: Security improvements

## Security Guidelines

- Never commit API keys, passwords, tokens, or private credentials.
- Keep sensitive environment variables in a local .env file.
- Use .env.example for placeholder configuration.
- Review staged files before committing.

## Testing

Run relevant tests and verify application behavior before opening a pull request.

## Pull Requests

Include a clear description of changes, testing performed, and relevant screenshots.
