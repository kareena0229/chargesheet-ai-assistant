# Security Policy

## Supported Project

Security issues affecting the current version of ChargeSheet AI Assistant can be reported for review.

## Reporting a Vulnerability

If you discover a security vulnerability:

1. Do not publish API keys, passwords, tokens, or private information.
2. Avoid sharing sensitive vulnerability details in public issues.
3. Provide a clear description of the issue and steps to reproduce it through a private communication channel with the project maintainer.

## Security Best Practices

- Never commit `.env` files or secret credentials.
- Store sensitive configuration in environment variables.
- Use `.env.example` with placeholder values.
- Validate uploaded documents and file types.
- Keep project dependencies updated.
- Review code changes before merging pull requests.

## Responsible Disclosure

Please allow the maintainer an opportunity to investigate and address reported security issues before publicly disclosing them.
